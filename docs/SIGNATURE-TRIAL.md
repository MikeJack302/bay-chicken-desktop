# 招牌动作独立试验 · 2026-11-03

基于 v0.7.0 / c580595，在 `experiment/signature-dances` 独立工作树试作。正式版源码、已发布 EXE、桌面快捷方式不变。试验版使用 `bay-chicken-trial` 用户目录、`BayChickenTrial` 进程名，不注册正式版的全局快捷键。首次打开只读取正式版的名字、颜色和大小，供外观对照，不复制聊天记录或密钥。

## 参考与核验

- 小红书站内搜索返回“安全限制 / IP 存在风险 / 300012”，没有绕过限制或自动登录。
- 在 B 站找到并查看 [《好得意的舞狮小飞～》](https://www.bilibili.com/video/BV1kgEh6rEmu/) 和 [《大湾鸡_飞鸡舞狮》](https://www.bilibili.com/video/BV1CRhF6WE7Y/)。参考交替抬脚、头部下探、踏步与弹起节奏；动作是程序编排的简化试作，不声称一比一复刻。
- [《大湾鸡跳芭蕾》](https://www.bilibili.com/video/BV1p4miBtEET/) 能看到单脚提腿和伸臂，但不足以确认用户提到的“芭蕾 oi”。本版 Oi 招呼明确标为待对照，不合入正式版。
- [《蘑菇蹲蘑菇蹲～谁能拒绝大湾鸡宝宝！！》](https://www.bilibili.com/video/BV1ZtSgBmEfq/) 提供蹲低的风格参考，但未确认就是用户说的“蘑菇”角色的劈腿蹲。先试深蹲，再试保守幅度。

## 质量判断

深劈腿版本在现有单段短腿和躯干蒙皮上产生明显的腹部折叠，未达到正式版标准。第二轮将张腿、俯身和躯干下沉幅度收小，折叠减轻，但腹部轮廓仍不够自然，因此未正式合入。Oi 缺少准确原片，不以抬手招呼冒充完整招牌动作。舞狮的交替抬脚、点头和轻跳可以保留为试作。当前仅提供独立试验，不替换 v0.7.0，也不发布正式更新。

## 验证

- 26 项单元测试通过，新增动作的完整周期、暂停、打断、从凳子/趴边切换，以及模型整体缩放保持均有检查。
- 对 v0.7.0 既有动作逐帧比较，818400 个原有姿态字段相同。
- 实机采集白粉两色的动作关键帧、完整录屏和劈腿蹲侧视图，检查结束后恢复站姿、道具收起、无渲染异常。
- 原始 GLB 与默认相机距离不变。没有将试验动作加入自主行为或部位随机反应池。
- 实际打包后的 EXE、asar 入口、试验版名字和版本已验证；配置夹隔离测试确认只继承外观，正式版的历史和密钥未复制，正式配置文件未写入。原正式 EXE 的 SHA-256 完全一致。

运行：`node scripts/build.mjs`，`node scripts/signature-preview.cjs`。打包仅生成独立便携 EXE：`pnpm exec electron-builder --config electron-builder.trial.yml --win portable --x64 --publish never`。
