# 湾湾大湾鸡 v0.7.0 · 起名字，更自然地玩

这版支持给桌宠起自己的名字，重做网球拍和挥拍动作，并调整四边趴靠。原始白粉模型、默认尺寸、已有大小设置和左右键操作继续保留。

## 改名字

点面板左上角的名字，或进入「设置」第一项，填写后保存。最多 16 个字，支持完整表情；留空恢复“湾湾”。底栏、面板、托盘和对话中的称呼同步更新，下次打开也会记住。改名不会改变已保存的大小。

## 网球

- 重做粗椭圆拍框、开放 Y 形喉部、横梁、八角短握把和螺旋缠带，采用 16×19 线床，调整小网球与拍面的比例。
- 对打由侧身引拍、稳定支撑脚、身体带动击球、顺势随挥与回位组成。
- 发球保留左手抛球、目光追踪和右手引拍；提示气泡提前淡出。
- 「…」→「动作与玩具」里选择网球对打、抛球发球和好球庆祝。

## 趴边

- 分阶段伸手、抓稳、靠住；左右边探头时头部反向轻倾，手臂分担支撑，腿部小动作错开。
- 保留呼吸、眨眼、眼神跟随、摸头和表情反应，摸头不会重新播放抓边过程。
- 四边吸附、拖走恢复、Esc 取消、手动贴边与自动吸附开关继续可用。按显示器可用桌面计算，底边通常为任务栏上沿。
- 贴边不会重置当前缩放，模型归一化高度和默认相机距离不变。
