# 湾湾大湾鸡 v0.5.0 · 操作体验更新

这次将移动和旋转分到不同鼠标按键，并完善取消、帮助、故障重试与退出保存。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖动 | 搬家，松手保存位置 |
| 右键拖动 | 左右转身、上下看俯视和仰视 |
| 左键轻点 | 对应部位的随机小反应 |
| 右键轻点 / 「…」 | 打开互动面板 |
| 滚轮 / 双击 / R | 缩放 / 回正视角 |
| Esc | 取消当前拖动；搬家返回原位 |
| 方向键 / Shift + 方向键 | 搬家 / 加快 |
| Alt + 方向键 / +、− | 旋转 / 缩放 |
| F1 | 操作指南 |

键盘操作需先点一下玩偶。F8 显示/隐藏，Ctrl + Alt + B 打开面板；若快捷键被占用，可从托盘操作。

## 改进

- 6 像素防抖、双击保护；搬家和转动不会同时触发摸头或弹出面板。
- 丢失捕获、失焦、隐藏时停止拖动；拖动中暂停角色动作，松手恢复。
- 修复高 DPI 连续移动导致窗口膨胀的问题，同时保持底栏贴近玩偶。
- 操作指南含版本、找回桌宠、快捷键状态和下载新版入口。
- 加载或图形显示异常时可重新加载，退出前保存位置。
- 保留原始白粉模型、26 种动作、8 部位随机反应与三种玩具。

## 下载与升级

- **BayChicken-Setup-0.5.0-x64.exe**：Windows x64 安装版，中文向导。
- **BayChicken-Portable-0.5.0-x64.exe**：单文件便携版，首次需等待解包。设置仍保存在 Windows 用户目录。
- **BayChicken-Xiaohongshu-Kit-v0.5.0.zip**：更新后的 6 张竖图、实机截图与文案。
- **SHA256SUMS.txt**：下载文件校验值。

更新前先从托盘退出旧版，再覆盖安装或运行新的便携 EXE。沿用 `%APPDATA%/bay-chicken` 下的设置和聊天数据。不会自动联网安装更新。

形象互动不需要 API Key。AI 聊天需自行配置服务，未配置时为预设回应。程序未做代码签名；已在本机 Windows x64 完成验证，实体多显示器组合尚未逐一覆盖。验证记录见 `docs/verification-v0.5.0.md`。
