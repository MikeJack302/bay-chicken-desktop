# 湾湾大湾鸡 v0.8.0-beta.2

新增 macOS Apple Silicon 与 Intel 版本，保留三维互动、动作表情、道具和轻提醒。

## 选择系统

| 系统 | 安装文件 |
| --- | --- |
| Windows x64 | `BayChicken-Beta-0.8.0-beta.2-x64.exe` |
| macOS Apple Silicon | `BayChicken-Beta-0.8.0-beta.2-mac-arm64.dmg` 或同名 `.zip` |
| macOS Intel | `BayChicken-Beta-0.8.0-beta.2-mac-x64.dmg` 或同名 `.zip` |

macOS 要求 13 Ventura 或以上。打开 DMG 后将应用拖入“应用程序”，再从那里启动。菜单栏图标可显示、隐藏、打开设置和退出；触控板可用 Option + 左键拖动旋转，鼠标仍支持右键拖动旋转。

## 功能与兼容

- 保留白粉模型、改名、举重与弓步、连跳、动作表情、网球、凳子、糖葫芦、风车和屏幕边缘互动。
- 保留喝水、起身活动、放松眼睛、自定义提醒、间隔设置、暂停与延后。
- Windows 与 macOS 使用各自的本机配置；Beta 使用独立配置目录。
- macOS 为 ad-hoc 签名 Beta，未做 Apple Developer ID 公证。首次打开如遇系统拦截，请按 [macOS 使用说明](https://github.com/MikeJack302/bay-chicken-desktop/blob/main/docs/MACOS.md) 和 Apple 官方说明确认来源，不需要关闭系统安全功能。

附件 `SHA256SUMS.txt` 包含本版本各安装文件的校验值。

[选择其他版本](https://github.com/MikeJack302/bay-chicken-desktop/blob/main/docs/DOWNLOADS.md)。v0.6.0、v0.7.0、v0.8.0-beta.1 继续提供，旧安装包未被覆盖。
