# 湾湾大湾鸡 v0.8.0-beta.1 🐔

这版把第三轮的立体腿脚、动作表情和轻提醒整理成公开 Beta。Windows x64，非官方个人作品。

## 新增与优化

- **轻提醒**：喝水、起身活动、放松眼睛与自定义内容；每项 1–240 分钟，独立开关，支持试播、暂停、延后 5 分钟。
- **立体腿脚**：重建有厚度的连续网格，加入膝盖和固定骨长约束，弓步时转移重心、前腿弯曲后腿支撑，结束后收脚。
- **动作表情**：招手眨眼、跳舞笑眼、吃糖葫芦满足、举重发力与完成后的放松、睡觉闭眼；表情有平滑过渡。
- **新玩法**：蓝色三维杠铃、弹簧连跳、小飞狮步和蹲姿试作；保留网球、凳子、糖葫芦、球、风车与屏幕趴边。

## 下载与使用

下载附件 **`BayChicken-Beta-0.8.0-beta.1-x64.exe`**，双击运行。模型已打包，无需 Node.js；动作和提醒不需要 API Key。

- 左键拖动移动，右键拖动旋转，滚轮缩放，双击回正。
- **… → 设置 → 轻提醒**，选择内容和间隔，点 **保存提醒**。默认关闭，也可先试播。
- 提醒仅在程序运行时工作；隐藏、暂停或忙于互动时顺延，重启/电脑唤醒后重新计时，不连续补发过期提醒。
- Beta 使用独立的 `bay-chicken-beta` 配置目录，不覆盖稳定版或之前的试验版；首次只继承名字、颜色与大小。使用托盘显示/隐藏或退出。
