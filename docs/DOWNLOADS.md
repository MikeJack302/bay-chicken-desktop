Mac 版需要 macOS 13 Ventura 或以上。安装、触控板操作与首次打开说明见 [macOS 指南](MACOS.md)，ZIP 备用包见对应 Release。

每个 Release 的 `SHA256SUMS.txt` 可用于校验对应版本的软件文件。[查看全部历史发行版](https://github.com/MikeJack302/bay-chicken-desktop/releases)。

稳定版和 Beta 使用独立配置。升级或回退前先退出当前运行的桌宠，再打开需要的版本。
