# 推荐标题

我做的大湾鸡桌宠，会提醒喝水了🐔

# 正文（可直接复制）

因为太喜欢大湾鸡，准备广州旅行的时候，就想先让它住进我的桌面🐔

于是做了这只小桌宠，最近终于整理成 Beta 版啦。

白白和粉粉都能选，名字可以自己起。左键带它搬家，右键转着看；摸摸脑袋会有小反应，还会找凳子坐、吃糖葫芦、打网球，趴在屏幕边缘陪你。

这次给它补了圆乎乎的小腿和好多小表情：招手会眨眼，跳舞会笑，举完杠铃还会露出“终于结束啦”的表情🥹

还加了一个我自己很需要的功能：喝水、起来活动、看看远处，都能自己设间隔，也能写自定义提醒。到点它就挥挥小手提醒我，忙的时候可以点“5 分钟后再说”。

Windows Beta 已放到 GitHub：
MikeJack302 / bay-chicken-desktop
到 Releases 里选 v0.8.0-beta.1 就能找到。

喜欢这种可爱小桌宠，可以先关注我呀🐔
后面学会新动作、更新新玩法，我都会继续发。一起看它慢慢变得更灵动～

你最想让它下次学会什么小动作？

非官方个人小作品，Beta 还在打磨，欢迎反馈。
