# 湾湾大湾鸡 v0.4.0 · Windows x64

一只可以旋转、坐小木凳、吃糖葫芦的三维桌面伙伴。白色和粉色外观可切换，采用原始 GLB 模型，交互动作由程序骨骼驱动。

## 下载哪个文件

- **BayChicken-Setup-0.4.0-x64.exe**：中文安装向导，可选目录，附桌面与开始菜单快捷方式。
- **BayChicken-Portable-0.4.0-x64.exe**：单文件便携版，双击解包运行。首次启动需等待解包；设置和聊天记录仍存放在 Windows 用户目录。
- **BayChicken-Xiaohongshu-Kit-v0.4.0.zip**：6 张 1080×1440 小红书配图、原始实机截图、长短两版文案和配图顺序。
- **SHA256SUMS.txt**：下载文件校验值。

无需安装 Node.js，模型已内置；形象互动不需要 API Key。程序未做代码签名。

## 这一版可以玩什么

- 拖动进行三维旋转，滚轮缩放；双击、R 键或回正按钮复位。
- 发现旁边的小木凳、挪过去坐好；点击凳子起身。
- 分几口吃糖葫芦、抛接小球、吹风车，可坐着继续玩。
- 脑袋、头顶水花、眼睛、肚子、手、脚、尾巴、后背，8 个部位各有随机反应，避免同一部位连续重复。
- 26 种姿态、动作与表情，保留眨眼、目光跟随、自主动作和暂停。
- 底栏随模型位置停靠，画布在窗口和 DPI 变化时同步更新。
- 紧凑的互动面板，启动默认收起；点底栏「…」→「动作与玩具」即可开始。

拖动六点手柄，或按住 Shift 拖玩偶，可以移动桌宠窗口。F8 显示 / 隐藏。

聊天是独立会话，需要自行配置模型服务；未配置时仅提供离线预设回应。
