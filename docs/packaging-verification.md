# v0.4.0 发布验证

验证日期：2026-10-29。环境：Windows x64，Electron 45.1.0、Three.js 0.186.1、electron-builder 26.18.0。

| 项目 | 结果 |
| --- | --- |
| `node --test tests/*.test.cjs` | 14 项通过，包含流式聊天、安全设置、动作、随机部位反应、底栏边界和视角 |
| 原始模型 | 三个 GLB 的 SHA-256 与 `research/model-provenance.json` 一致 |
| EXE 安装包 | 在工作区内全新隔离目录静默安装成功，生成真实 `BayChicken.exe` 与卸载程序 |
| 安装后的应用 | `scripts/props-smoke.cjs` 通过：窗口/DPI 画布、3 种大小的底栏距离、找凳子、坐姿保留、3 种道具、点击凳子起身、8 个真实部位点击、同部位不连续重复 |
| 单文件便携 EXE | `scripts/portable-smoke.cjs` 通过：自解压、asar 与 preload 加载、原始模型、凳子、糖葫芦、小球、风车，未出现渲染错误 |
| 隔离数据 | 验证启动均传入 `--smoke`，使用临时用户目录，不读取个人聊天或密钥 |
| 小红书配图 | 6 张 PNG 均为 1080×1440，逐张检查排版，源自真实应用截图 |

原有三维旋转、顶视/底视、眼球、暂停、白粉外观和聊天回归由 `scripts/smoke.cjs` 验证；该测试的聊天只连接本机模拟服务，不调用付费模型。

这些检查是在本机 Windows 环境完成的功能与安装验证，不代表所有硬件环境均已覆盖，也不是数字签名或杀毒认证。代码签名未配置。便携版仍将设置与聊天保存在 Windows 用户数据目录。

发布文件校验值见 Releases 中的 `SHA256SUMS.txt`。原始透明截屏与来源记录随分享素材 ZIP 提供。
