GitHub Windows CI 配置见 `.github/workflows/ci.yml`：冻结依赖安装、单元测试、构建。发布前另核对当次执行结果。EXE 与素材包上传后以 GitHub 返回的 SHA-256 对照本地文件校验。

所有功能测试均使用 `--smoke` 隔离数据目录。移动验证在隔离进程内使用可控原生光标替身，鼠标/键盘事件由 Playwright 注入，真实窗口的位置和尺寸由 Windows 接口检查。实体不同 DPI 多显示器组合、所有显卡驱动与不同 Windows 版本尚未逐一覆盖。测试不代表数字签名或杀毒认证，发布包未配置代码签名。
