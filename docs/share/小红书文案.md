# 广州还没去，大湾鸡先养上了🥹

因为真的很喜欢大湾鸡，又刚好马上要去广州旅游，就给自己做了一只可爱的小桌宠。🤍

还没出发，它先住进我的电脑里了。

可以给它起个自己喜欢的名字，转着看看圆乎乎的脑袋，摸摸头、戳戳肚子，它会有不一样的小反应。

最喜欢它趴在屏幕边边的样子，偷偷探个头看你，有一点小时候养 QQ 宠物的感觉。🥹

它还会认真找个小凳子坐好，吃几口糖葫芦，挥挥球拍，再给自己庆祝一下。看着看着，就忍不住想点它两下。🍡🎾

现在一边期待广州旅行，一边让它在桌面陪我等出发。

也分享给同样喜欢大湾鸡的朋友，你会给它起什么名字呀？

Windows 版也打包好了，放在 GitHub：MikeJack302/bay-chicken-desktop。

个人制作的非官方桌宠，配图都是实机截图。
