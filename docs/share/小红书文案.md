# 正文（可直接复制）

最近和 Codex 一起，把大湾鸡做成了一只 Windows 三维桌宠，取名「湾湾」。🥹

这次最想做好的，是它陪你玩的小动作。

拖一下就能转着看，正面、侧面、背面都有；滚轮还能放大缩小。白色和粉色也可以切换。

我最喜欢的是「坐下」：它会发现旁边的小木凳，挪过去，抬腿坐好。然后拿串糖葫芦，一颗颗吃。还有抛接小球、吹风车，眼神会跟着一起动。🍡

摸脑袋、戳肚子、点眼睛、小手或脚丫，反应也不一样。转到后面，尾巴和后背同样能互动。同一个部位有多种随机反应，尽量不连续重复。

界面做得小小的，底栏跟着它走，平时淡出。需要时点「…」→「动作与玩具」，就能陪它玩一会儿。

已经打包成 Windows x64 EXE，安装版和单文件便携版都放在 GitHub Releases 了。
