# 湾湾大湾鸡 v0.6.0 · 网球和屏幕趴边

保留原始白粉模型，新增网球动作和像 QQ 宠物一样的屏幕边缘互动。

## 新增动作

- **网球对打**：准备接球、挥拍、看着球飞走、小碎步调整。
- **抛球发球**：抛起荧光小网球，再挥拍击球。
- **好球庆祝**：举起球拍，开心蹦一蹦。

在底栏「…」→「动作与玩具」中选择。三维球拍与网球会随视角转动，点击球或球拍可重播。

## 屏幕趴边

- 左键拖到当前屏幕可用桌面边缘，松手自动吸附。
- 左右边侧身探头、顶边倒挂、底边趴着，保留眨眼、看你和小幅晃动。
- 轻点部位仍有反应；拖走、右键拖动旋转或开始网球等运动，会回到正常姿态。
- Esc 取消拖离，回到原来的边缘。
- 可在设置关闭自动趴边；面板和托盘也有手动贴边入口。
- 手部对齐实际边界，工具栏留在内侧，屏幕外的模型区域被裁去并停止命中，趴边状态会保存。

边缘按显示器的可用桌面计算，底边通常是任务栏上沿。不是对其他应用窗口边框的吸附。
